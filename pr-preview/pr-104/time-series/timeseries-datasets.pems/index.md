# Time Series Dataset: PEMS

> [!NOTE]
>
> **In one minute**
>
> Traffic data from the California PeMS system and how to download it (registration required). No examples are shown yet.

California Department of Transportation (Caltrans) Performance Measurement System (PeMS) provides traffic data on [their website](<https://pems.dot.ca.gov/?dnode=Clearinghouse>). To download the data[^/time-series/timeseries-datasets.pems/#how-to-download],

- Register on the website and wait for approval, then login.
- Go to [this page](<https://pems.dot.ca.gov/?dnode=Clearinghouse>) and choose the data we need using the filter on the top.

  - For example, we choose Type = `Station 5-Minute` and District = `District 3`.

We do not show examples of this dataset here.
